# Economy and logistics

경제의 정식 역할은 영토를 키우기 위한 독립 성장 게임이 아니라 `회복한 땅이 다음 탐사와 결계 유지에 기여하게 만드는 것`이다.

- [Territory utility and infrastructure](./territory-utility-and-infrastructure.md): 핵심 역할과 위치 기반 시설 계약 **accepted**, 상세 시설·생산식 **under-validation**
- [Cargo slots and logistics](./cargo-slots-and-logistics.md): 슬롯형 적재와 실제 경로 운송 **accepted**, 정확한 슬롯 수·preset UI **under-validation**
- [Iron mine](./iron-mine.md): 가능한 재료 시설 예시 **provisional**
- [Forge and equipment](./forge-and-equipment.md): 가능한 변환 시설 예시 **provisional**

제출본은 첫 편입 타일의 샘과 물 보충만 포함한다. 완제품 경제, 노동자 배치, 다중 생산망, 방어구와 무기 숙련은 **deferred**다.
