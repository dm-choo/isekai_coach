# Local area and scouting

## Hierarchy

```text
섹터
└─ 영역 타일
   └─ 로컬 영역
      ├─ 중앙 방
      ├─ 상·하·좌·우 경계 방
      ├─ 중앙 방과 경계 방을 잇는 통로
      └─ 통로 구간
```

- 월드 타일 하나는 중앙 방 하나와 상·하·좌·우 경계 방 네 개를 항상 가진다.
- 각 경계 방은 독립된 통로 하나로 중앙 방과 연결된다.
- 인접 월드 타일이 없는 방향도 경계 방과 내부 통로는 유지하되 바깥 출구를 봉쇄한다.
- 열린 출구로 이동하면 인접 월드 타일의 반대편 경계 방에 진입한다. 예를 들어 동쪽 출구는 다음 타일의 서쪽 경계 방과 연결된다.
- 방은 본격 전투, 시설, 보상과 사건을 담는다.
- 통로는 일반적으로 3~5개의 순서 있는 구간으로 나뉘며 각 구간은 이동 또는 인카운터 슬롯 하나를 담는다.
- 통로 구간의 인카운터 종류는 `없음`, `전투`, `함정`, `사건`, `자원`이다. 실제 slice는 필요한 일부 종류만 선택해 구현한다.

```text
                    [북쪽 경계 방]
                           │
                     통로 3~5구간
                           │
[서쪽 경계 방] ─ 통로 ─ [중앙 방] ─ 통로 ─ [동쪽 경계 방]
                           │
                     통로 3~5구간
                           │
                    [남쪽 경계 방]
```

## Encounter lifecycle

통로 인카운터는 다음 두 종류의 생명주기 사건에서 추첨한다.

1. 월드 생성 시 해당 타일이 구체화되면 최초 구성을 추첨한다. 아직 구체화하지 않은 타일은 최초 진입 시 한 번 추첨한다.
2. 클리어한 타일을 관리하지 않아 `밝음 → 흐림`으로 재침식될 때 새 구성을 다시 추첨한다. 안정화와 방치가 반복되면 재침식될 때마다 다시 추첨할 수 있다.

- 한 번 추첨한 결과는 타일 상태에 저장한다. 저장·불러오기, 방과 통로의 왕복 또는 전투 재시도로 다시 추첨하지 않는다.
- 추첨 시점마다 encounter generation을 증가시켜 최초 구성과 재침식 구성을 구분한다.
- 전투 해석에는 무작위를 넣지 않는다. 인카운터 구성 추첨과 [결정론적 전투](../combat/turn-and-intent.md)는 서로 다른 단계다.
- 재침식되어도 시설, 지형과 이미 소비한 일회성 보상은 유지한다.
- 재침식 시 중앙 방은 다시 적에게 점거되고 이전 통로 정찰 정보는 현재 정보로 취급하지 않는다.

## Scouting

- 정찰은 확률 판정으로 발생하지 않는다.
- 중앙 방의 핵심 위협 또는 목표를 해결하면 해당 월드 타일의 네 통로 전체가 즉시 정찰된다.
- 정찰 결과는 각 통로 구간의 `안전`, `전투`, `함정`, `사건`, `자원` 종류와 위치를 공개한다.
- 적의 정확한 종류·수치와 사건의 구체적인 내용은 해당 구간에 진입하기 전까지 숨긴다.
- 재침식된 타일은 중앙 방을 다시 클리어해야 새로 추첨된 통로 구성이 다시 정찰된다.

## Tile clear

월드 타일은 다음 조건을 모두 만족하면 클리어된다.

1. 중앙 방의 핵심 위협 또는 목표를 해결했다.
2. 진입 경계 방에서 다음 열린 출구까지 이어지는 안전 경로를 하나 확보했다.

클리어에 사용하지 않은 다른 통로의 선택 인카운터는 남아 있을 수 있다. 모든 통로와 방을 비우는 것은 완전 탐색이지 기본 클리어 조건이 아니다.

## Local exploration

- 방과 통로 구간은 서로 연결된 로컬 장면이며 각 장면 안에서는 자유 이동한다.
- Slice 2에서 지도 node 선택은 즉시 위치 변경이 아니라 다음 100m 구간의 방향 선택이다. 선택 뒤 A/D를 누르는 동안 횡스크롤 통로에서 이동하며 100m 끝의 인카운터에서 자동 정지한다.
- 뒤로 이동해 0m에 도달하면 시간과 위치를 정산하지 않고 출발 node로 복귀한다. 100m를 완주했을 때만 이동 2분을 정산한다.
- 경계 방의 열린 출구, 통로의 앞·뒤 구간과 중앙 방을 통해 장면 사이를 이동한다.
- 전투 지점이나 통로 전투 구간에 진입하면 현재 장면 위에 grid를 활성화한다.
- 전투 종료 후 같은 자유 이동 장면으로 돌아온다.
- 정찰된 전투는 붉은 기척이나 오라로 암시한다.

세계 시간은 WASD 입력 횟수가 아니라 통로·지점 이동, 전투 턴과 시설 상호작용 같은 의미 있는 사건으로 계산한다.

## Rest and field supplies — Slice 2 validation

- 원정 시작 시 물 1, 식량 1과 휴대용 조명 1을 가진다.
- 물과 식량은 각각 최대 2개까지 운반한다.
- 해결된 중앙 방 또는 안전한 경계 방에서만 휴식한다.
- 휴식 한 번은 물 1, 식량 1과 세계 시간 20분을 소비하고 관리자·동료 HP를 각각 3 회복한다.
- 두 전투원의 HP가 모두 최대면 휴식할 수 없다.
- 정찰 가능한 일회성 물·식량 인카운터가 있다. 가방이 가득 차면 보상을 소비하지 않고 현장에 남긴다.
- 물·식량 보상은 재침식으로 복원되지 않는다.
