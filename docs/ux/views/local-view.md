# Local view UX

- 월드 타일 하나는 중앙 방, 네 경계 방과 이를 연결하는 네 통로로 읽혀야 한다.
- 방과 통로 구간은 연결된 개별 로컬 장면이며 현재 장면 안에서 주인공을 자유 이동한다.
- 통로 전후 이동과 방 진입은 방향이 유지되는 짧은 장면 전환으로 표현한다.
- 열린 경계 출구는 인접 월드 타일로, 봉쇄된 출구는 진행 불가 상태로 명확히 구분한다.
- 상호작용 가능한 시설·장치에는 contextual prompt를 표시한다.
- 중앙 방 클리어 전에는 통로 인카운터를 미확인 상태로 표시한다.
- 중앙 방 클리어 뒤에는 전체 통로에서 인카운터 종류와 위치를 표시하고, 정찰된 전투는 붉은 기척이나 오라로 미리 암시한다. 정확한 적과 사건 내용은 진입 전까지 숨긴다.
- 전투가 시작되면 장면을 교체하기보다 현재 장면 위에 grid와 HUD를 활성화한다.
- 전투 종료 뒤 같은 장면의 자유 이동으로 복귀한다.

월드 시간 비용은 키 입력이 아니라 gameplay의 의미 있는 이동·전투·상호작용 사건에서 계산한다.
