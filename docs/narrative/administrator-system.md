# Administrator system

관리자는 전장 밖의 원격 운영자가 아니라 직접 이동하고 공격하는 전투원이다. 관리자 권한은 주인공이 세계 복구와 결계 확장을 수행할 수 있는 서사적·시스템적 근거다.

- 전투 중 자신의 행동을 직접 선택한다.
- 동료는 탐사·전투·경로 확보를 대신할 수 있지만, 영토의 최종 편입과 핵심 관리자 유적의 활성화는 주인공만 수행한다.
- 주인공은 확보한 인접 타일의 확장 거점을 기존 결계망에 연결해 결계선을 바깥으로 이동시킨다.
- 거점, 안정화 장치와 시설 복구가 하나의 관리자 상호작용 계열로 느껴질 근거를 제공한다.
- 물리 세계의 체크포인트와 별개로 관리자 지식이 유지되는 서사적 근거를 제공한다.

영토 편입과 장치 효과는 [Barrier territory](../gameplay/world/barrier-territory.md), rollback과 지식 보존은 [Failure, save and recovery](../gameplay/operations/failure-save-and-recovery.md)가 소유한다.

관리자 시스템의 원래 제작자와 목적은 **deferred**다. 시스템은 플레이어 행동을 정답/오답으로 판정하는 인격적 코치가 아니다.
