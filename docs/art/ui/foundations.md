# UI art foundations

- 아마존 정글의 흙·잎·결계문 물성을 장면의 바탕으로 두고, HUD는 Darkest Dungeon식 contextual bottom control처럼 작고 명확하게 둔다.
- 관리자의 청백 신호와 적의 붉은 경고는 scene을 보조하며, 화면 전체를 편집기·계기판처럼 지배하지 않는다.
- 적 위험은 빨강, 동료 예상과 관리자 시스템은 파랑·청백·청록을 사용하되 icon, pattern, stroke와 motion을 병행한다.
- playfield를 dashboard처럼 덮지 않고 현재 턴·Intent·HP/AP·행동에 필요한 정보만 계층화한다.
- 색만으로 의미를 구분하지 않고 icon, pattern, stroke와 motion을 병행한다.
- 16:9, 4:3와 390px viewport에서 playfield와 HUD 우선순위를 유지한다. 캐릭터가 충분히 크게 보이고 일부 겹치는 것을 허용한다.

이전 ChatGPT 생성 UI preview나 임의 template 이미지는 canonical reference가 아니다.
