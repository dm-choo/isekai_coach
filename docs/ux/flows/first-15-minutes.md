# First 15 minutes UX flow

이 문서는 첫 15분의 학습 순서와 사용자 이해 기준을 소유한다. 정확한 콘텐츠 순서는 [Submission first 15 minutes](../../submission/first-15-minutes.md)가 소유한다.

## Learning progression

1. 로컬 자유 이동과 contextual interaction으로 직접 조작을 학습한다.
2. 주인공 단독 전투에서 grid와 적 Intent를 읽는다.
3. 장비 획득과 비콘 재가동으로 세계 복구를 연결한다.
4. 동료 해방 뒤 본대와 별동대 역할 차이를 이해한다.
5. 본대 합동 전투에서 주인공 행동이 동료 prediction을 바꾸는 것을 본다.
6. 별동대 자동전투를 작전 채널에서 관전한다.
7. 분석 모드에서 비효율의 객관적 원인을 확인한다.
8. 정책 우선순위를 한 번 바꾸고 다음 실제 전투에서 개선을 검증한다.

## Acceptance

15분은 엔딩이 아니다. 플레이어가 `정책 자동행동`, `미지 개척`, `시설·장비 복구를 통한 돌파`라는 게임의 약속을 이해하면 성공이다. 자연어 예측 문장이나 시스템의 정답 판정으로 이해를 대신하지 않는다.
