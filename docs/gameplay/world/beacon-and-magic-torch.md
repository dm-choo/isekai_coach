# Beacon and magic torch

## Beacon

- 섹터 거점이며 관리자 권한으로 재가동한다.
- 반지름 3칸을 흐림으로 공개하고 대장간·던전 같은 주요 오브젝트를 실루엣으로 표시한다.
- 봉인된 동료 2명을 해방하고 작전 채널·관리자 기능을 활성화한다.
- 철광산은 반경 안에서 다른 스프라이트로 감지되며 동료 A가 조사 의사를 밝힌다.

## Magic torch

- 설치 타일 하나를 영구적으로 밝음 상태로 안정화한다.
- 주변 8칸을 흐림 이상으로 공개한다.
- 시설과 별동대 물류 경로를 안정화하고, 결계 해제 뒤에도 섹터 관리에 사용한다.

길 건설은 현재 **deferred**다.
