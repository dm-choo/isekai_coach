# Local view UX

- 월드 타일 하나는 중앙 방, 네 경계 방과 이를 연결하는 네 통로로 읽혀야 한다.
- 방에서는 월드 공간에 놓인 문을 선택한다. 전체 화면 내부 지도나 100m node 선택 UI는 사용하지 않는다.
- 문을 한 번 고르면 다음 방까지 400m 횡스크롤 통로를 A/D로 연속 이동한다. 파티의 화면 위치는 고정하고 배경과 지면이 반대 방향으로 흐른다. 네 100m 판정 지점의 인카운터는 자동으로 이동을 멈추며, 해결 뒤 같은 통로를 이어 간다.
- 소형 구조도는 비조작 상태 HUD이며 현재 방, 진행 방향과 정찰된 위험만 표시한다. 구조도 바깥의 굵은 출구 화살표와 다음 월드 타일 번호가 local scale과 world-route scale을 잇는다.
- 열린 경계 출구는 인접 월드 타일로, 봉쇄된 출구는 진행 불가 상태로 명확히 구분한다.
- 상호작용 가능한 시설·장치에는 contextual prompt를 표시한다.
- 중앙 방 클리어 전에는 통로 인카운터를 미확인 상태로 표시한다.
- 중앙 방 클리어 뒤에는 전체 통로에서 인카운터 종류와 위치를 표시하고, 정찰된 전투는 붉은 기척이나 오라로 미리 암시한다. 정확한 적과 사건 내용은 진입 전까지 숨긴다.
- 언어를 읽지 못해도 문 실루엣, 화살표, 파티의 이동, 100m 눈금, 위험 glyph 순으로 거친 의미를 이해해야 한다. 텍스트는 상세 설명에만 사용한다.
- 물·식량·조명은 번역 문자를 icon으로 대체하지 않고 프로젝트 소유 drop/loaf/torch silhouette를 사용한다.
- 전투가 아닌 모든 장면에서 파티 초상 버튼으로 캐릭터 HP·기술과 동료 5-slot 우선순위를 확인·재정렬할 수 있다. 기본 상태는 접혀 있고 progression gate가 아니다.
- 전투가 시작되면 장면을 교체하기보다 현재 장면 위에 grid와 HUD를 활성화한다.
- 전투 종료 뒤 같은 장면의 자유 이동으로 복귀한다.

월드 시간 비용은 키 입력이 아니라 gameplay의 의미 있는 이동·전투·상호작용 사건에서 계산한다.
