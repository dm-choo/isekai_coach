# Main party and detachment

## Submission roster

- 총 3명: 주인공과 동료 2명
- 부대 최대 2명
- 본대: 주인공 + 동료 1명
- 별동대: 동료 1명

## Roles

본대는 미지 탐색, 첫 조우, 새 기믹, 관리자 시설, 주요 내러티브, 보스와 결계를 담당한다.

별동대는 알려진 적 자동 교전, 자동 개척, 흐린 타일 재확보, 채집·운송과 반복 업무를 담당한다. 성장·훈련은 장기 가능성이지만 제출본 핵심 계약은 아니다.
