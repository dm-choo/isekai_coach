# First 15 minutes UX flow

이 문서는 첫 15분의 학습 순서와 사용자 이해 기준을 소유한다. 정확한 콘텐츠 순서는 [Submission first 15 minutes](../../submission/first-15-minutes.md)가 소유한다.

## Learning progression

1. 초기 결계선과 바로 바깥 frontier를 한 화면에서 보고 현재 영역을 구분한다.
2. 로컬 자유 이동과 contextual interaction으로 결계 밖 첫 좌표에 직접 진입한다.
3. 본대 합동 전투에서 grid, 적 Intent와 동료 prediction을 행동으로 읽는다.
4. 중앙 방 확보가 네 통로 정찰을 일으키는 것을 본다.
5. 직전 전투에서 막힌 정책·공간 원인 하나를 확인하고 한 곳만 수정한다.
6. 정찰된 통로에 동료 작전을 배정하고 주인공의 거점 조사와 동시에 진행한다.
7. 작전 결과에서 실제 경로, 정책 발동, 피해와 시간을 확인한다.
8. 주인공이 확장 거점을 활성화하고 결계선·샘·다음 좌표가 바뀌는 것을 본다.

## Acceptance

15분은 완제품 엔딩이 아니다. 플레이어가 `미지는 직접 배운다`, `알려진 공간은 정책으로 맡긴다`, `그 결과가 실제 영토와 다음 확장 능력으로 남는다`는 약속을 이해하면 성공이다. 자연어 예측 문장이나 시스템의 정답 판정으로 이해를 대신하지 않는다.
