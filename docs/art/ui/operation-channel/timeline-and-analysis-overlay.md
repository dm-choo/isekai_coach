# Timeline and analysis overlay

- LIVE, 과거 타임시프트와 현재 시점 복귀를 timeline 위치와 상태 label로 구분한다.
- Routine은 압축하고 Notable과 Decision은 밀도·icon·강조로 구분한다.
- Watch mode는 playfield 우선, Analysis mode는 당시 상태와 정책 이유 overlay를 추가한다.
- analysis overlay는 적의 미확인 내부 정책을 노출하지 않는다.
- 특정 스트리밍 서비스 UI 외형을 복제하지 않는다.
