# UI art foundations

- 흑연과 검정을 기반으로 날카로운 백색 기술선과 기하학적 frame을 사용한다.
- 편집 디자인과 기술 HUD의 인상을 지향한다.
- 적 위험은 빨강, 동료 예상과 관리자 시스템은 파랑·청백·청록을 사용한다.
- playfield를 dashboard처럼 덮지 않고 필요한 정보만 계층화한다.
- 색만으로 의미를 구분하지 않고 icon, pattern, stroke와 motion을 병행한다.
- 16:9와 4:3 모두에서 playfield와 HUD 우선순위를 유지한다.
