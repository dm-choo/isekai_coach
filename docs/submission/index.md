# Submission

OpenAI Game Builders Seoul 제출용 Web Build가 전체 게임 설계에서 선택하는 범위와 완료 기준을 소유한다. 최종 게임 타이틀은 아직 확정하지 않으며 `Isekai Coach`는 현재 프로젝트명이다.

이 디렉터리는 gameplay 규칙을 새로 만들지 않는다. 각 항목은 [Gameplay](../gameplay/index.md), [Narrative](../narrative/index.md), [UX](../ux/index.md), [Art](../art/index.md)의 canonical owner를 링크한다.
