# Combat grid art

- 약간 위에서 내려다보는 2.5D side-view projection을 지원한다.
- 기본 grid는 장면을 방해하지 않을 정도로 은은하다.
- 선택, Intent, prediction과 이동 경로가 있는 셀만 명확히 강조한다.
- 행과 점유 관계, 캐릭터 baseline이 16:9와 4:3에서 즉시 읽혀야 한다.
- logical grid 크기와 renderer projection 수치를 시각 정본으로 고정하지 않는다.
