# Canonical terminology

| Term | Meaning |
| --- | --- |
| 주인공 / Protagonist | 플레이어가 직접 행동 후보와 관리자 상호작용을 선택하는 여성 관리자 |
| 동료 / Companion | action-policy로 자동 행동하는 인간형 생명체 |
| 본대 / Main party | 주인공과 동료 1명으로 구성된 탐색·주요 전투 부대 |
| 별동대 / Detachment | 동료 1명이 맡는 자동 교전·개척·물류 부대 |
| 초기 결계 / Initial barrier | 주인공이 깨어난 작고 안정된 최초 영토 |
| 결계선 / Barrier contour | 편입된 타일들의 외곽을 따라 실제로 그려지는 안전 영역의 경계 |
| 확장 거점 / Expansion anchor | 확보한 인접 타일을 기존 결계망에 연결하는 관리자 장치 또는 지형 거점 |
| 지역 핵 / Regional core | 섹터의 장거리 결계 연결과 관리자 기능을 회복하는 주요 유적. 모든 타일 편입을 대신하지 않는다. |
| 안정화 장치 / Stabilizer | 편입 타일의 불안정화 위험을 낮추거나 제거하는 지역 장치 |
| 편입 / Incorporation | 확보한 인접 타일을 결계 안의 영토로 영구 등록하는 주인공 행동 |
| 불안정 / Instability | 영토 소속은 유지되지만 안전 이동·생산·정찰 일부가 손상된 상태 |
| Intent | 적이 실행 전에 공개하고 방향·anchor를 잠그는 행동 예고 |
| Prediction | 현재 전투 상태에서 궁수 동료가 다음에 수행할 것으로 공개된 자동행동 |
| 행동 정책 / Action policy | 위에서 아래로 평가하는 최대 5개의 원자 행동 우선순위 |
| 작전 채널 / Operation channel | 부대별 실제 작전 사실, 다시보기와 분석 진입점 |
| 관전 모드 / Watch mode | 전투 연출과 실제 행동 중심 재생 모드 |
| 분석 모드 / Analysis mode | 당시 상태와 정책 판정 이유를 조사하는 모드 |

`student`, `Warrior`, `Spearman`은 현재 scaffold의 테스트 식별자이며 최신 서사 정본의 캐릭터명이나 직업명이 아니다. 최종 게임 타이틀도 아직 확정하지 않는다.
