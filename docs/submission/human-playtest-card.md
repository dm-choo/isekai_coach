# 제출본 V5 무설명 플레이테스트 카드

## 진행자 규칙

- 참가자에게 `https://openai.ktwome.cc/`만 준다.
- 키, 목표, 장르를 설명하지 않는다.
- 90초 동안 같은 장면에서 진행이 없을 때만 `화면에서 지금 할 수 있어 보이는 것은 무엇인가요?`라고 묻는다.
- 정답을 알려주지 않고 참가자가 화면을 해석하는 말을 그대로 적는다.
- 두 사람을 같은 build에서 테스트한다. 변경이 생기면 이전 결과와 섞지 않는다.

## 관찰 기록 — 한 사람당 여섯 줄

```text
참가자 코드 / build SHA / 시작 시각:
첫 행동 (초):
첫 전투 시작 / 첫 plan 확정 (초):
정책 선택과 참가자가 말한 이유:
위임 결과에서 먼저 본 손익:
결계 확장의 원인을 참가자가 한 말 / 막힌 지점:
```

## 종료 질문 — 답을 유도하지 않는다

1. 시작한 땅과 처음 조사한 땅은 무엇이 달랐나요?
2. 동료가 방금 그 행동을 한 이유는 무엇이라고 생각하나요?
3. 바꾼 정책은 무엇을 얻고 무엇을 잃었나요?
4. 결계가 왜 커졌으며, 다음에는 어디로 가고 싶나요?

## 판정

- 2/2가 도움 없이 첫 조우를 시작하고 plan을 확정한다.
- 2/2가 위임을 시작하고 HP·시간·경로 중 둘 이상의 손익을 찾는다.
- 2/2가 `직접 탐사/정찰 → 정책/위임 → 주인공 거점 → 결계 확장` 중 세 연결 이상을 자기 말로 설명한다.
- 최소 1명이 다음 좌표나 필요한 준비를 자발적으로 말한다.

실패하면 설명문부터 추가하지 않는다. 가장 먼저 끊긴 `행동 발견 → 입력 → 수락 피드백 → 결과` 연결 하나만 새 Goal로 연다.
