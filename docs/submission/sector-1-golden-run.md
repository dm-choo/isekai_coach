# Submission golden run

## Complete cycle

```text
초기 결계에서 동쪽 frontier 선택
→ 직접 통로 이동과 첫 조우
→ 중앙 목표 해결과 전체 통로 정찰
→ 직전 행동 원인 확인
→ 동료 정책 한 곳 수정
→ 동료를 알려진 동쪽 통로에 위임
→ 주인공은 중앙 방에서 확장 회로 연결 준비
→ 공유 시간으로 두 작전 해결
→ 안전해진 동쪽 통로를 지나 경계 방의 확장 거점 활성화
→ frontier 타일 편입과 결계선 이동
→ 샘 활성화와 물 보충
→ 다음 좌표 공개
```

## Player choices

골든 패스가 하나여도 입력 결과가 자동으로 정답화되지는 않는다.

- 직접 전투에서 관리자가 피해를 대신 받으며 동료 사격선을 지킬지, 둘 다 안전하게 이동해 시간을 쓸지 선택한다.
- 정책 수정은 공격 우선과 사거리 유지 중 무엇을 위에 둘지 선택한다.
- 동료 위임 시 피해 한도 초과 후퇴와 물 사용 허용 여부를 선택한다.
- 휴식하면 HP를 회복하지만 세계 시간과 물·식량을 잃는다.

각 선택은 `HP`, `시간`, `보급`, `경로 확보` 중 둘 이상에 서로 다른 결과를 남겨야 한다. 어느 선택도 모든 축에서 항상 우월하면 안 된다.

## Provisional encounter fixture

제출본의 공간 학습은 새 적을 많이 소개하지 않고 기존 고블린 두 종류와 배치 차이로 만든다.

1. 서쪽 통로의 고블린 전사 1명이 `이동 종착점 → 근접 공격 footprint`를 가르친다.
2. 중앙 방의 고블린 전사 1명과 궁수 1명이 접근 압박, 최소 사거리와 전열 차폐를 함께 드러낸다.
3. 정찰된 동쪽 통로는 같은 두 적을 다른 시작 거리·행에 배치한다. 새 규칙이 없으므로 동료에게 위임할 수 있다.
4. 원거리 동료의 `사거리 유지` 지침은 피해를 줄일 수 있지만 즉시 사격 횟수와 완료 시간을 희생할 수 있다.

적 HP·피해·시작 좌표는 **provisional**이다. 이 fixture의 역할은 적 가짓수보다 `직접 본 규칙이 다른 배치의 위임에도 전이되는가`를 검증하는 것이다.

## Authoritative contracts

- 거시 좌표와 방·통로 배치는 고정한다.
- 통로 인카운터는 저장된 seed를 사용하고 retry로 다시 추첨하지 않는다.
- 직접·위임 전투는 같은 결정론적 simulation을 사용한다.
- 주인공과 동료가 분리된 동안 같은 세계 시간이 흐른다.
- 동료가 새 적 태그나 알 수 없는 Decision을 만나면 해당 부대만 중단한다.
- 동료 작전 성공만으로 타일을 편입하지 않는다. 주인공이 안전해진 동쪽 통로를 실제로 지나 경계 방의 확장 거점을 활성화해야 한다.
- 편입 뒤 결계선은 타일 외곽으로 이동하고 샘 효용과 다음 인접 좌표가 열린다.

## Automated evidence

새 제출 검증 명령은 최소 다음을 고정 seed로 재현해야 한다.

1. 초기 결계와 frontier의 영토 상태가 다르다.
2. 중앙 목표 전후 `corridorsScouted`가 변한다.
3. 정책 수정 전후 동일한 알려진 조우에서 행동 또는 결과가 달라진다.
4. 위임 결과가 같은 simulation의 사건 기록을 남긴다.
5. 동시 구간 뒤 양쪽 작전의 경과 시간이 하나의 세계 시각에 합쳐진다.
6. 안전 경로가 없거나 주인공이 거점에 없으면 편입할 수 없다.
7. 편입 뒤 contour, territory, utility와 다음 좌표가 함께 갱신된다.
8. save/load와 retry가 encounter generation과 결과를 바꾸지 않는다.

기존 `verify:combat-ux`, `verify:slice2`는 회귀 suite로 유지하되 새 제품 acceptance를 대신하지 않는다.

## Human evidence

새로운 사람에게 게임 설명과 키 설명을 하지 않고 관찰한다.

- 첫 망설임과 잘못된 입력 시각
- 입력이 적용됐다고 판단한 화면 피드백
- 동료 행동 원인에 대한 자기 설명
- 위임 전 예상과 위임 후 실제 결과
- 결계가 왜 커졌고 샘이 왜 열렸는지에 대한 설명
- 다음에 하고 싶다고 말한 좌표 또는 준비 행동

`재미있다`보다 인과 설명과 다음 의도를 먼저 기록한다.
