# Failure, save and recovery

## Expedition defeat

초기 캠페인은 permadeath를 사용하지 않는다. 패배한 부대는 마지막 안전한 편입 타일로 후퇴하며 다음 비용을 현재 세계에 남긴다.

- 작전에 실제로 소비한 세계 시간과 보급
- 부상 또는 회복 필요 상태
- 운반 중인 비보호 적재품 일부 또는 전부
- 미완료 목표와 해당 경로의 위협
- 조건을 충족한 외곽 타일의 불안정화 진행

도감 관찰, 정책 수정과 이미 편입한 영토는 유지한다. 제출본은 손실 수치를 단순화할 수 있지만 패배를 세계 전체 롤백으로 지우지 않는다.

## Detachment defeat

세계는 롤백하지 않는다. 별동대는 마지막 안전한 편입 타일로 후퇴하고 작업을 취소한다. 전투 기록은 유지하며 플레이어가 마지막으로 유효했던 좌표, 정책 판정과 후퇴 원인을 볼 수 있어야 한다.

## Autosave

월드 타일 진입·편입, 작전 배정, 전투 종료와 Decision 확정 시 자동 저장한다. 저장은 encounter seed를 유지하며 불리한 결과를 다시 추첨하지 않는다. 정확한 수동 저장 정책은 **under-validation**이다.

## Sector objective completion

지역 핵 또는 주요 위협을 해결하면 다음 확장 범위가 열린다. 이전 영토와 불안정 상태는 유지되며, 섹터 목표 완료가 모든 타일의 자동 편입이나 캠페인 상태 삭제를 일으키지 않는다.
