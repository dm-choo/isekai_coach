# Regional core and stabilizer

## Regional core

- 지역 핵은 섹터의 장거리 결계망과 관리자 기능을 복구하는 주요 유적이다.
- 활성화하면 섹터의 중요한 좌표, 확장 거점 또는 구조 신호를 추가로 공개할 수 있다.
- 지역 핵은 인접 타일을 자동 편입하지 않으며, 동료나 주민을 일괄 해방하는 만능 보상 장치가 아니다.
- 지역 핵의 핵심 보상은 더 먼 확장을 가능하게 하는 결계 용량·연결·정보 중 하나다.

## Stabilizer

- 안정화 장치는 편입 타일 하나 또는 명시된 연결 구간의 불안정화 위험을 낮춘다.
- 안정화는 시야 공개, 위협 제거 또는 영토 편입을 대신하지 않는다.
- 시설과 자동 작업이 의존하는 핵심 경로에 먼저 설치할 이유를 만든다.

정확한 설치 자원, 범위와 유지비는 **under-validation**이다. 기존 build의 `비콘`과 `마력 횃불` 명칭은 각각 지역 핵과 안정화 장치의 임시 표현으로만 남아 있으며 새 구현의 의미 계약이 아니다.
