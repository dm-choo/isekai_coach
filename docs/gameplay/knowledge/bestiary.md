# Bestiary knowledge

- 적 기술을 한 번 관찰하면 그 기술의 전체 기본 규칙을 공개한다.
- 거리·HP별 반복 관찰 노동을 요구하지 않는다.
- 모든 기술을 관찰하면 `기술 기록 완료` 상태가 된다.
- 정확한 적 정책 우선순위는 제출본에서 자동 공개하지 않는다.
- 장기적으로 관찰한 상태·특성 태그를 전술 언어에서 해금한다.

도감은 디자이너가 만든 닫힌 정답형 교전 protocol을 제공하지 않는다. 행동 모델 추론·검증 UI는 **deferred**다.
