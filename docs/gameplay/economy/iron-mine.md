# Iron mine

- 철광산은 유한한 노출 광맥이다.
- 철 원석을 채집하며 별동대를 배치해 자동 채집할 수 있다.
- 광맥 고갈은 Decision 사건으로 별동대를 대기시킨다.
- 무한 방치 우위를 만들지 않는다.

첫 섹터의 정확한 총 원석 수는 **provisional**이며 현재 약 6개 후보이다.
