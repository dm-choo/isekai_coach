# Action and system VFX

공격 순간, 지역 핵 복구, 확장 거점 연결과 결계 contour 이동은 정보 VFX보다 더 강한 감정적 밀도를 허용한다.

- 공격은 key pose, action shape, hitstop과 camera feedback을 결합한다.
- 관리자 장치는 청백 광학 glyph와 scan을 사용하되, 결계 확장은 원형 pulse 하나가 아니라 기존 contour에서 새 타일 외곽으로 선이 이어지고 땅의 생기·환경 반응이 뒤따르는 시간적 인과로 표현한다.
- 적 공격은 붉은 arc, wedge와 warning pulse를 사용한다.
- 화려한 연출 뒤에도 실제 결과 cell과 대상이 모호해지지 않아야 한다.

완성 VFX asset 제작은 현재 문서 작업 범위가 아니다.
