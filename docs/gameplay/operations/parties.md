# Main party and detachment

## Campaign structure

- 주인공이 포함된 부대 하나를 본대로 취급한다.
- 동료는 한 명 이상이 별동대를 구성해 서로 다른 실제 좌표의 작전을 수행할 수 있다.
- 모든 부대는 같은 월드 시간과 영토 상태를 공유한다.
- 정확한 완제품 인원수, 부대 최대 크기와 동시 별동대 수는 **under-validation**이다.

## Submission roster

제출본은 주인공 1명과 동료 1명으로 증명한다. 주인공은 첫 조우를 혼자 해결하고 초기 결계 외곽에서 동료를 직접 합류시킨다. 이후 첫 합동 조우로 두 agency의 차이를 배운 뒤, 주인공의 거점 조사와 동료의 알려진 통로 확보를 잠시 분리해 최소 위임 루프를 만든다. 추가 동료와 두 개 이상의 동시 별동대는 제출본에서 **deferred**다.

## Roles

본대는 미지 탐색, 첫 조우, 새 기믹, 관리자 시설, 주요 내러티브, 보스와 결계 확장을 담당한다.

별동대는 알려진 적 자동 교전, 정찰된 경로 확보, 불안정 타일 재확보, 채집·운송과 반복 업무를 담당한다. 정확한 허용 조건과 중단 규칙은 [Delegated expeditions](./delegated-expeditions.md)를 따른다.
