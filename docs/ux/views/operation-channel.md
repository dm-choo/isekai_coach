# Operation channel UX

- 부대별 timeline에서 Routine, Notable과 Decision 사건을 구분한다.
- 현재 진행, 과거 다시보기와 현재 시점 복귀를 명확히 표현한다.
- Decision은 해당 별동대가 대기 중임을 보여주고 필요한 선택으로 연결한다.
- Watch와 Analysis 전환은 플레이어가 명시적으로 수행한다.
- 다시보기 중 세계 시간이 멈췄음을 알린다.
- 정책 변경은 미래 작전에만 적용된다는 경계를 유지한다.

정확한 시각 구성은 [Operation channel art](../../art/ui/operation-channel/index.md)가 소유한다.
