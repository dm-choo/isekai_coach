# Action bar and policy label art

- 주인공 action bar는 하단 중앙에 두고 playfield를 최소한만 가린다.
- 선택 상태, AP 비용과 후보 prediction 연결을 명확히 표현한다.
- 동료 행동 순간 작은 정책 label/card를 짧게 노출한다.
- 전체 정책 판정표처럼 보이는 상시 dashboard로 확장하지 않는다.
- 정확한 icon, typography와 spacing은 16:9·4:3 prototype에서 검증한다.
