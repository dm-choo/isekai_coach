# Administrator system

관리자는 전장 밖의 원격 운영자가 아니라 직접 이동하고 공격하는 전투원이다. 관리자 권한은 주인공이 세계 복구와 정보 관리를 수행할 수 있는 서사적·시스템적 근거다.

- 전투 중 자신의 행동을 직접 선택하고, 승리 뒤 세계 오브젝트의 봉인을 해제한다.
- 비콘, 시설, 특수 회로와 결계의 봉인을 해제한다.
- 비콘, 횃불과 시설 복구가 관리자 상호작용으로 일관되게 느껴질 근거를 제공한다.
- 물리 세계의 체크포인트와 별개로 관리자 지식이 유지되는 서사적 근거를 제공한다.

비콘·횃불의 효과는 [Beacon and magic torch](../gameplay/world/beacon-and-magic-torch.md), rollback과 지식 보존은 [Failure, save and recovery](../gameplay/operations/failure-save-and-recovery.md)가 소유한다.

관리자 시스템의 원래 제작자와 목적은 **deferred**다. 시스템은 플레이어 행동을 정답/오답으로 판정하는 인격적 코치가 아니다.
