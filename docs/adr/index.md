# Architecture decision records

ADR은 현재 규칙 전체가 아니라 후속 구조를 제약하는 선택의 이유와 대안을 기록한다. 규칙의 최신 전문은 각 ADR의 canonical docs가 소유하고, 대체된 전문은 Git history에서 조회한다.
