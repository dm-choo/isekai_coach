이 폴더는 UI·카메라·전투 장면을 비교하기 위한 외부 reference 보관소다. 저장된 이미지는 복제할 production asset이 아니며, `docs/research/reference-insights.md`와 `docs/art/` 문서에서 문제와 정보 계층을 분석할 때만 사용한다.

Dungeon Fighter Online은 [공식 Steam store page](https://store.steampowered.com/app/495910/Dungeon_Fighter_Online/)의 side-scrolling 2D action framing과 hit feedback을 분석 대상으로 삼는다. 저장소에 공식 이미지 파일을 복제하지 않고 링크로 추적한다.

## Usage rules

- 파일명·출처·확인 날짜를 보존한다.
- 외부 이미지를 game asset, UI mockup 또는 최종 art의 seed로 취급하지 않는다.
- 문서에서 가져오는 것은 해결한 문제(장면 우선, 깊이, 순간적 telegraph)와 trade-off이며 표면 복제가 아니다.
- 라이선스·재배포 권리가 확인되지 않은 이미지는 production bundle이나 public build에 포함하지 않는다.
