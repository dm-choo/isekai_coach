# Combat view UX

- 카메라는 약간 위에서 내려다보는 2.5D side-view다.
- grid는 평소 은은하고 선택, 적 Intent와 동료 prediction에서 강조한다.
- 적 Intent, 동료 현재 예상과 주인공 후보 이후 예상을 서로 다른 정보 계층으로 보여준다.
- 주인공 행동 후보는 하단 중앙 action bar에서 선택한다.
- 동료가 행동할 때 실행 정책명을 작은 label/card로 잠깐 보여준다.
- 정책 전체 판정은 분석 모드에서만 보여준다.
- AP가 남은 동안 후보 행동과 prediction을 재계산한다.

색, cell highlight, 경로선과 icon의 시각 문법은 [Combat view art](../../art/ui/combat-view/index.md)가 소유한다.
