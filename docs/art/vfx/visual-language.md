# VFX visual language

Core language:

```text
white core + blue optical glow + geometric system glyphs
```

- 기본 형태는 ring, beam, arc, scan, wedge와 orbit이다.
- 내부는 날카롭고 외곽 bloom은 부드럽다.
- 아군·관리자 신호는 차갑고 정밀한 청백 광학 계열이다.
- 적 신호는 붉고 공격적인 경고 계열이다.
- 색 외에 형태, 방향, pattern과 timing으로 의미를 구분한다.
