# Character proportions and rendering

- 전투 sprite는 4.5~5.5등신 세미 데포르메다.
- 초상과 얼굴은 날카로운 애니메이션풍을 사용한다.
- 피부와 복장은 저채도·차가운 계열이며 거칠고 붓질이 느껴지는 러프 채색을 지향한다.
- 전투 크기에서는 머리, 복장과 무기 실루엣을 큰 덩어리로 읽히게 한다.
- 귀엽지만 유아적으로 만들지 않는다.
- 액션 pose는 게임 내 표시 크기에서 크게 읽혀야 한다.

정확한 해상도는 [asset generation and validation](../../development/codex/assets/generation-and-validation.md)의 in-engine 검증 뒤 확정한다.
